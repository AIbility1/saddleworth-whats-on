Community events

Everything the community has added, newest first — the review queue. Listings marked NEW arrived in the last 7 days. Edit fixes titles, categories, tags and wording in place; Remove is the backstop for anything dodgy.

Venue facts — hours, blurbs, tags

Fix a venue's card without a code change: whatever you set here overrides the built-in data the moment the map next loads. Leave a field empty to keep the site's own value; "Clear override" puts everything back.

Business submissions

"Add a missing business" entries wait here — nothing shows on the map until approved. Approving reveals the contact email and the venue's code.

Verified venues

Verifying locks a venue's listings to its code — hand the code to the landlord and only they (and you) can change that venue's events.
